### 🥋 The Ninja Way

> Not the loudest headband in the room — just the one who keeps showing up to the dojo after everyone else has gone home.

I'm an IT undergrad who treats **web application security like a shōnen training arc**: start as a rookie throwing SQLi payloads at DVWA, grind PortSwigger labs like side quests, and level up one CTF, one CVE writeup, one custom tool at a time. No shortcuts, no genjutsu — just recon, patience, and a stupid amount of curiosity about *why* things break.

Off duty, I'm probably re-watching a match/arc I've already seen twice, because both hacking and Haikyuu taught me the same lesson: **the boring reps are what make the clutch play possible.**
